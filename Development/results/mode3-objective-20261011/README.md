# MODE0 与 MODE3 强度1：客观对照

MODE3确实放大了现有NN修正，但没有多跑一次NN，也没有证据表明增加了新细节或提高了画质。本次复核使用旧真实HDR菜单：1296×720 RGBA16F输入，经1920×1080有效区域、1920×1152处理区的同一次NN运行，分别保存增强前后，并使用同一原始输入、同一个解码器解码；实际计数为NN调用1次、额外解码1次。增强前输出作为普通MODE0基线，因此排除了两次NN、不同seed带来的混淆。当前生产的低频host/shader、输入处理和codec源码与旧实验逐字相同，79个HIP模块也与当前安装逐SHA相同。[身份](source-identity.json) · [模块与当前运行日志](../mode3-stellar-live-audit-20261011/README.md)

这个真实帧的编码域残差MAE由0.01868645增至0.02713170，约增加45.2%；原始解码HDR RGB差量MAE为0.00198010，中位数0.00022602。双方使用同一曝光、Reinhard与sRGB预览映射后，显示RGB差量MAE约为4.51/255：正常全图相近，放大后脸部、头发更暗，眉眼边缘、衣料反差及色彩变化可见。这是已有修正的幅度/反差变化，不能用增强后的边缘反差证明恢复了真实细节。编码输出有最小−5.60e−9的浮点epsilon；1e−6容差下无越域，72行padding与解码alpha逐位不变，全部有限。区间计数只描述输出结果，不冒充headroom分支计数。[完整统计](old-menu/stats.json) · [全图与差分](old-menu/comparison.png) · [脸部/头发](old-menu/crop-1-x3.png) · [衣料](old-menu/crop-2-x3.png)
